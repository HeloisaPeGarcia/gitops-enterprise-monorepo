# Security Policy

## Supported Versions

We actively support and fix security issues in the following versions of our deployment manifests:

| Version | Supported |
|---------|-----------|
| Helm Chart v1.x | Yes |
| ArgoCD v2.10+ | Yes |
| Kubernetes 1.28+ | Yes |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability or a security issue within this deployment structure, please do **NOT** open a public issue.

Instead, please report security issues privately by emailing:
* **security@example.com**

Please include the following information in your report:
* The component affected (e.g., SealedSecrets, Ingress config, Rollouts).
* A detailed description of the issue or potential exploit.
* Steps to reproduce the issue.

We will acknowledge your report within 48 hours and provide a timeline for fixing the vulnerability.
